Players new to Minecraft for Nintendo Switch 2 may experience an error when first trying to play Offline. If you run into this error, please make sure to follow these steps as your Virtual Game Card may not be loaded:

1.  Go to the **Virtual Game Cards** tab on your Switch 2.
2.  Select Minecraft.
3.  Select **Load to this System**.

**Note:** If you receive the same error, you may need to restart your Switch 2.

For more information, please see [Virtual Game Card Guide \| Nintendo Support](https://en-americas-support.nintendo.com/app/answers/detail/a_id/67891/~/virtual-game-card-guide)
