We believe everyone should be empowered and enabled to play Minecraft Dungeons II. This article will focus on accessibility options available in Minecraft Dungeons II.    

**Note: Upon start-up, the first screen with interactivity on it is the Main Menu.  **

# Accessibility Settings 

Minecraft Dungeons II includes an Accessibility Menu. Select it from the Main Menu via the Settings menu, or from the in-game Settings menu.  

## Settings Available on the Accessibility Menu 

## Gameplay

- Guidance Trail – Toggle to enable or disable the guidance trail feature.

## Hearing

- Set audio output to mono – Combines all audio channels into a single mono mix, played equally through all speakers.
- Voiceover subtitles – Turn on to display subtitles for cutscene voiceover.
  - Subtitle text size – Adjust the size of subtitle text. Make it larger to read more easily, or smaller to fit more text on the screen.
  - Subtitle text color – Choose a color for subtitle text to make it easier to read or to match your visual preferences.
  - Subtitle background opacity – Add a background behind subtitle text to improve readability. You can make it more or less opaque to suit your preference.

## Screen Reader

- Screen reader – Enable spoken narration for menus and on-screen text to assist players with visual impairments.
- Screen reader volume – Adjusts how loud the screen reader is. Set higher for easier listening, or lower to keep it in the background.
- Screen reader speed – Adjust how fast the screen reader reads text aloud.

## Text

- Text size – Changes the size of in-game and menu text. Increase it to make text easier to read or decrease it to fit more text on the screen.
- Font style – Choose the style of text used in menus, subtitles, and on-screen prompts.
  - Stylized – Unique Minecraft fonts that match the game’s visual style.
  - Simplified – Simple, clear, and easy-to-read text.
- UI size – Adjust the size of the interface on your screen. This includes both menu and HUD elements but excludes text. Increase the size to make everything easier to see. Decrease the size to fit more of the game world on your display.
- Read time – Controls how long animated text like notifications stay on screen. Increase this setting if you need more time to read.

## Color

- Color blind mode – Adjusts the game’s colors to make important details easier to see.
  - None – Standard color settings.
  - Deuteranope – Helps if you have trouble seeing green tones.
  - Protanope – Helps if you have trouble seeing red tones.
  - Tritanope – Helps if you have trouble seeing blue tones.
- High contrast mode – Enhances the visibility of important elements by making them stand out more against the background.
- Custom Colors – Choose your own colors for key interface elements, like HUD, menus, and indicators. Personalize the look of the game or pick colors that are easier for you to see.

## Graphics

- Camera shake – Enable or disable camera shake effects during gameplay. Some in-game elements like explosions, big mobs, and level changes cause the camera to shake. Disable camera shake if you feel it’s too intense for you. 

## Accessible Menu Navigation and Narration

Minecraft Dungeons II (using English as a language) includes the ability to navigate the menus in an accessible way using a keyboard or controller. 

## About Menu UI Narration 

- If you have a screen reader enabled on your PC, Minecraft Dungeons II will automatically enable menu UI narration when the game is launched. 
- Menu UI narration can be enabled and disabled in the Accessibility Menu in the Screen Reader section. 

## Tips on Navigating Menus 

- Use a controller (or keyboard on PC) to navigate all menus in Minecraft Dungeons II.
- Use the Escape key as a shortcut to go back to the previous selection or close the current screen in Minecraft Dungeons II edition on PC. 

# Accessing the Friends Menu in Multiplayer 

When playing an Online game, you can open the Map on your controller and go to the Party menu. Once in the Party menu, you can see which of your Friends are online, and you have the option of inviting them to your game. 

# Future Accessibility Features 

Minecraft Dungeons II is working on improving the existing features and adding additional features for accessibility in future updates.
