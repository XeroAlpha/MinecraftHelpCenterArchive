# Understanding Platform and Profile Entitlements

When it comes to owning content in Minecraft, not all items are stored in the same way. Some items are tied to the platform where you purchased them, while others are tied to your game profile.

Understanding the difference can help explain why certain content appears on one device but not another.

# What Are Platform Entitlements?

Platform entitlements are items or content that are tied to a platform store account.

Examples include:

- Base game ownership
- Downloadable content (DLC)
- Deluxe Edition content
- Pre-order bonuses
- Content purchased through a platform storefront

Because these entitlements are managed by the platform where they were purchased, they may only be available when using that platform account.

Example: \
If you purchase Deluxe Edition content through a platform store, that purchase is associated with that platform's licensing system.

# What Are Profile Entitlements?

Profile entitlements are items linked directly to your game profile.

These items are managed by Minecraft's game services rather than a platform storefront.

Example: \
If you receive a promotional cape from a community event or redeem a cosmetic code, that item becomes part of your game profile's collection.

# Why Does This Matter?

If you're trying to find a missing cosmetic or determine where a redeemed reward should appear, the type of entitlement can make a difference.

# How Do I Redeem Cosmetic Codes?

Some promotions include a code that unlocks cosmetic content, such as a cape, pet, or skin.

The redemption process may vary depending on the promotion, but cosmetic rewards are typically redeemed through the game experience associated with the promotion.

Follow the instructions included with your code to redeem it.

After successful redemption:

1.  Sign in with the account you intend to use.
2.  Complete the redemption process described by the promotion.
3.  Restart the game if necessary.
4.  Check your customization, cosmetics, dressing room, inventory, or profile rewards area (depending on the game).

# Why Can't I Redeem My Code on a Storefront?

Promotional cosmetic codes are often different from game purchase codes.

A game or DLC code may be redeemed through a platform storefront.

A cosmetic code may instead be redeemed through a promotion-specific redemption flow designed for that reward.

Always follow the instructions included with your code.

# Missing Cosmetic Rewards

If a cosmetic reward, cape, pet, skin, or promotional item isn't appearing in-game, there are several steps you can take before contacting support.

## Verify the Correct Account

Many cosmetic rewards are associated with the account used during redemption or reward distribution.

Make sure you're signed in with the same account that:

- Redeemed the code
- Participated in the event
- Received the promotion

## Restart the Game

After a reward is granted, it may take time to appear.

Try:

1.  Closing the game completely.
2.  Signing out and back in.
3.  Restarting your device.
4.  Launching the game again.

## Check Where the Item Appears

Different rewards may appear in different locations.

Look in:

- Character customization menus
- Cosmetic collections
- Inventory screens
- Reward or profile sections

## Confirm the Reward Was Successfully Redeemed

If the item came from a code or promotion, verify that:

- The redemption was completed successfully.
- No error messages were displayed.
- The reward confirmation was received.

## After Linking or Unlinking Accounts

Some content may be associated with the account where it was originally redeemed or granted. If you've recently linked or unlinked accounts, verify that you're signed into the same account that received the reward. 

## Contact Support

If the reward is still missing, include:

- The name of the reward
- The promotion or event name
- Screenshots of any redemption confirmation
- The account used during redemption

# Troubleshooting Code Redemption Issues

Having trouble redeeming a code? This guide covers the most common redemption problems and their solutions.

## Error: Invalid Code

This message can occur when:

- The code was entered incorrectly.
- The code has expired.
- The code is not recognized by the redemption system. 

Double-check the code and try again.

## Error: Code Already Redeemed

Some codes can only be redeemed once.

If you receive this error:

- Verify that you haven't already used the code.
- Confirm that another account did not redeem the code previously.

## Error: Code Expired

Promotional codes may have redemption deadlines.

If a code has expired, it may no longer be valid for redemption. 

## Unable to Connect During Redemption

Some redemption systems require an internet connection.

Try:

1.  Verifying your internet connection.
2.  Restarting the game.
3.  Trying again later.

## I Redeemed a Code but Didn't Receive My Reward

If redemption was successful but the item does not appear:

- Restart the game.
- Confirm you're signed into the correct account.
- Check the area where the reward should appear.
- Allow some time for delivery. 

## Contact Support

When creating a support request, include:

- The code type
- The promotion name
- Screenshots of any error messages
- The date of redemption
- Redemption confirmation details, if available

Providing this information helps Support investigate your issue more quickly.
