You can view your Realms subscription expiration date in the platform store where you purchased your subscription. If you are unsure which platform the subscription is tied to, or unsure how to view subscription information on that platform:

1.  Launch Minecraft and select **Play**.
2.  Select the **Realms** tab.
3.  Select the **Realms Hub** for the Realm you want to reset.
4.  Select the **Settings** tab.
5.  Select **Subscription**.
6.  Select **Manage Subscription**.

If you are on the same platform where you purchased the subscription, you will be routed to the store. Otherwise, you will see instructions on how to find your subscription details on the platform you purchased it on.
