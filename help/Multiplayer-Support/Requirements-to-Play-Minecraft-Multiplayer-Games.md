If you want to play multiplayer games or Realms in Minecraft: Bedrock Edition or Minecraft: Java Edition, here’s what you need for a successful connection:

- **Matching game versions**: You need Bedrock Edition to join a Bedrock Edition world, server, Realm, or Local Area Network (LAN) game.  Java Edition players can only join Java Edition hosted games. Learn about [Differences Between Minecraft: Java Edition and Minecraft: Bedrock Edition](../Buying-Minecraft-Games/Differences-Between-Minecraft-Java-Edition-and-Minecraft-Bedrock-Edition.md).
- **Latest Minecraft release**: See our [Download & Install](https://help.minecraft.net/hc/en-us/sections/27166490706957) section to update Minecraft to the newest version and avoid errors.
- **Minimum system specifications for computers:** Computers must meet or exceed [Minecraft: Java Edition System Requirements](../Download-Install/Minecraft-Java-Edition-System-Requirements.md) to avoid connection and performance issues.
- **Internet and/or LAN connection: **Your gaming device must have a strong and stable connection to the internet and/or network.
- **Active premium online subscription for consoles**: To play Minecraft multiplayer on a console, subscribe to [Xbox Game Pass Core](https://www.xbox.com/en-US/xbox-game-pass) or [PlayStation Plus](https://www.playstation.com/en-us/ps-plus/). Nintendo Switch players must also subscribe to [Nintendo Switch Online](https://ec.nintendo.com/US/en/membership/) for online multiplayer.
- **Invitation for Realms**: To join a Minecraft Realm, contact the Realm host to get an invite. See [Create or Join Realms](https://help.minecraft.net/hc/en-us/sections/26104084764557) for more.
- **Microsoft Account for consoles, mobile devices**: Link or sign in with your Microsoft account to play on a console or mobile device. See [Use or Link Microsoft Accounts](https://help.minecraft.net/hc/en-us/sections/29296773863181) for information.
- **Enable multiplayer permissions**: Child accounts must enable permissions to join multiplayer games. See [Managing Multiplayer Game Access for a Child Account in Minecraft](../Account-Settings/Managing-Multiplayer-Game-Access-for-a-Child-Account-in-Minecraft.md).
