Below is a list of input actions in Minecraft: Java Edition. Most of these actions can be rebound by going to **Options \> Controls \> Key Binds.**

**Scroll** - When in the game view in creative, survival or adventure mode, it scrolls through your hotbar. When in spectator mode, it changes your flying speed. When in a menu or GUI with a scroll bar, it moves the scroll position.

**Esc** - Opens the game menu and allows cursor control. It also pauses single-player games. 

**F1** - Toggles the HUD 

**F2** - Takes screenshots and stores them in your [.minecraft](../Backup-Restore/Find-Your-Minecraft-Java-Edition-Backup-World.md) folder 

**F3** - Toggles the debug overlay. Holding **F3** and then pressing certain other keys allows you to perform additional debug actions; see the Debug section at the bottom of **Options \> Controls \> Key Binds** for a complete list. 

The following key combinations are most commonly used:

- **F3 + 1** - Toggles a pie chart showing performance impactors. While it is active, pressing a number key (0-9) will change the scope of the chart. (The number input may trigger other actions such as switching the hotbar slot).
- **F3 + 2** - Toggles a graph showing the frame rate (and, if in a world, another graph showing the tick rate)
- **F3 + F4** - Opens the game mode switcher if you have operator permissions
- **F3 + F6** - Opens the Debug Options screen, allowing you to customize the information in the debug overlay and enable or disable debug renderers
- **F3 + A** - Reloads all chunks
- **F3 + B** - Toggles entity hitboxes
- **F3 + C** - Copies your location to the clipboard. Hold for 10 seconds to trigger a crash.
- **F3 + D** - Clears the chat
- **F3 + G** - Toggles chunk boundaries
- **F3 + H** - Toggles detailed item tooltips
- **F3 + N** - Cycles between spectator mode and the previous game mode
- **F3 + P** - Toggles the auto-pause when the window loses focus
- **F3 + T** - Reloads resource packs
- **F3 + Esc** - Pauses the game without bringing up the pause menu

## Movement Input Actions:

- **Space** - Jump 
- **Double Tapping Space** - Toggles fly mode in creative mode
- **Left Shift** - Sneak 
- **Left Control** - Sprint 
- **A** - Strafe Left 
- **D** - Strafe Right 
- **S** - Walk Backward 
- **W** - Walk Forward 

## Shift + Left Mouse Button Interactions: 

- Clicking an item or stack will move it between inventory and stack. 
- When a container is open, **shift + clicking** on an item will move up to a stack between the container and the inventory. 
- When a furnace is open, **shift + clicking** an item or stack in the furnace moves it to the applicable inventory slot. 
- When crafting, **shift + clicking** on the crafted item automatically crafts the maximum number of the selected item for the materials to be used (up to one stack), and it will move all the crafted items to the inventory. 
- In the survival inventory tab of the creative inventory, **shift + clicking the ‘X’** clears the whole inventory in any other tab**. Shift + clicking** an item puts a stack into the hotbar.

## Mouse Controls

- **Left Mouse** - Attack/Mine 
- **Middle Mouse (Scroll wheel button)** - Switch to the hotbar slot containing the item which spawns or places the block or entity you are looking at. If the item is in your inventory instead of your hotbar, it is moved to your first empty hotbar slot, and you switch to that slot. If you do not have the item, but are in creative mode, the item appears in your hotbar, replacing your main hand item stack if necessary. 
- **Right Mouse** - Use Item/Place Block 

## Other Keyboard Controls

- **1-9 Number keys** - Select hotbar slot of the number you pressed 
- **E** - Open Inventory 
- **F** - Swap item stacks in your main hand and offhand
- **G** - Quick Actions
- **L** - Advancements
- **P** - Social interactions
- **Q** - Drop item 
- **Ctrl + Q** - Drop item stack
- **F4** - Toggles the shader effect which appears when spectating certain entities
- **F5** - Toggles perspective (first person/third-person rear-view/third-person front-view)
- **F11 -** Toggles fullscreen

## Creative Mode 

- **X + 1-9 Number Key** - Loads Toolbar Activator 
- **C + 1-9 Number Key** - Saves Toolbar Activator  

## Multiplayer

- **Tab** - See the List of Players 
- **While in chat window + tab** - Cycles through possible commands or arguments and auto-completes player names 
- **T** - Open Chat 
- **/** - Open Command (Open the chat window with “/” character already entered) 
- **Shift + Up Arrow/Down Arrow** - In the multiplayer server selection menu, **shift + up** and **shift + down** moves a server name to a specific position. You can also hold shift while a server name is selected and left click on another server name; they will swap positions in the menu.
