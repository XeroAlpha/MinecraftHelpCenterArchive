Launching a Realm world in Minecraft Editor allows you to make large-scale changes to your world directly on the server. 

## Requirements

In order to launch a Pro Realm in Minecraft Editor, the following requirements must be met:

- You are the Realm owner or an Administrator. See: [Create Admins for your Minecraft: Bedrock Edition Realm](../Manage-Realms-Settings/Create-Admins-for-your-Minecraft-Bedrock-Edition-Realm.md) for more information.
- You are using Minecraft: Bedrock Edition on PC.
- The Realms Server Mode is set to **Play and Editor** or **Editor Only**. See [Manage Server Mode for Minecraft Realms Pro](./Manage-Server-Mode-for-Minecraft-Realms-Pro.md) for more information.

## Instructions

If all the above requirements are met, use the following steps to Launch in Minecraft Editor:

1.  Launch Minecraft: Bedrock Edition.
2.  Select **Realms** from the **Menu**. 
3.  Select the **Realm** you want to launch in **Editor**.
4.  Select **Launch in Editor.**

**Note:** If you do not see the **Launch in Editor** button, one of the requirements listed above was most likely not met. 

For more information, see: [Understanding Minecraft Editor Integration in Realms Pro](./Understanding-Minecraft-Editor-Integration-in-Realms-Pro.md)
