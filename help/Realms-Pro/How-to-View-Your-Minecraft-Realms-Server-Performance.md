Realms Pro introduces a new feature where owners and Administrators can monitor their Realms server performance in real time and over time. Track CPU, memory usage, player count, and server tick time to stay on top of performance as your Realm grows and gains more members. 

**Note:** Only owners and Administrators will be able to view server performance. Server performance metrics are not available for Preview Realms.

Here’s how to find it:

1.  Visit [Minecraft.net](https://www.minecraft.net/en-us)
    1.  If you are not already signed in, sign in with the **Account** button. 
    2.  If you are already signed in, go to your profile by clicking on the **Account** button and then selecting **Profile**.
2.  Select **Bedrock Realms**.
3.  Select **Realms Pro**.
4.  You should see any Pro Realms that you own or are an Administrator for.
5.  Select **Server Performance** on the Realm you want to see.

## Live Metrics

Live metrics update every five seconds while the Realm is online. 

## Historical Metrics

Historical metrics let you see your Realm’s performance over time. Select a particular metric from the dropdown to see a chart of that metric’s value over the following periods of time:

- 30 minutes: 1 data point per 60 seconds.
- 1 hour: 1 data point per 2 minutes.
- 24 hours: 1 data point per hour.
- Last 7 days: 1 data point per 6 hours.
- Last month (4 weeks): 1 data point per day.

**Note:** The table below the line chart will include data for the same time period as the line chart but will include values for all metrics.

To learn more about live and historical metrics, see [Understanding Realms Pro Server Performance](./Understanding-Realms-Pro-Server-Performance.md)
