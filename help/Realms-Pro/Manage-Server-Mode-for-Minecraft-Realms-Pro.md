The Minecraft Realms Pro Server Mode setting allows owners and Administrators to control whether players or Minecraft Editor users can join the Realm.

1.  Launch Minecraft: Bedrock Edition.
2.  Select **Realms** from the **Menu**.
3.  Select the Realm you want to adjust from the list of Realms on the left and select **Realm Hub**. 
4.  Select **Settings**.
5.  Select **Server**.
6.  Scroll down to **Server Mode** and choose which players can join the Realm:
    1.  **Play and Editor:** Everyone can play, **and** the owner and Admins on Windows devices will also be able to use Editor on this Realm.
    2.  **Play Only:** Everyone can play. No one can launch in Editor.
    3.  **Editor Only:** The owner and admins on Windows devices can launch in Editor. No one can play.

**Note:** If you change the Server Mode while players are online, the Realm will have to be restarted. You’ll get a warning when you leave the Server Settings tab and can choose to either proceed with your change and restart the server or disregard your change. If you restart the server, everyone online will be disconnected. Once the restart finishes, they’ll be able to rejoin.

For more information about Minecraft: Bedrock Edition Realm Settings, see [Manage Settings for Your Minecraft: Bedrock Edition Realm](../Manage-Realms-Settings/Manage-Settings-for-Your-Minecraft-Bedrock-Edition-Realm.md)
