**Posted:** 14 August 2026

A new hotfix is rolling out to address issues found in the latest update. It will become available on each platform as it’s approved, so please allow a little time for it to reach you.

# Fixes:

## Commands

- Removed self selection expansion when using commands (i.e. `/tell`) for non-operator players. ([MCPE-241436](https://bugs.mojang.com/browse/MCPE-241436))

## Graphical

- Vibrant Visuals are no longer disabled when loading a world with Education features enabled ([MCPE-240476](https://bugs.mojang.com/browse/MCPE-240476))

## Input

- Pressing the Back button on Android now performs the expected in-game back action instead of moving the game to the background ([MCPE-241324](https://bugs.mojang.com/browse/MCPE-241324))

## Items

- Arrow shot by a slightly charged Bow no longer hits the shooting player ([MCPE-240527](https://bugs.mojang.com/browse/MCPE-240527))

## Stability and Performance

- Fixed an issue that could disconnect players while loading worlds with certain add-on content ([MCPE-241505](https://bugs.mojang.com/browse/MCPE-241505))

## User Interface

- Shift-clicking items in Creative mode while using Pocket UI no longer deletes them and instead quick-moves them to available inventory slots ([MCPE-241415](https://bugs.mojang.com/browse/MCPE-241415))

# Technical Updates

## Dimensions

- Fixed a bug where `minecraft:dimension_bounds` and other values defined in a dimension JSON file were ignored ([MCPE-241528](https://bugs.mojang.com/browse/MCPE-241528))
