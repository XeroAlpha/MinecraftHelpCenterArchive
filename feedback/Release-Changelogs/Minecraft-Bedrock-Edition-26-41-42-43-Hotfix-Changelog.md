**Posted:** 10 August 2026

A new hotfix is rolling out to address issues found in the latest update. It will become available on each platform as it’s approved, so please allow a little time for it to reach you.

## Fixes:

- Fixed several crashes that could occur during gameplay
- Fixes for missing assets when loading into a world that could occur if the network connection changed during boot.

## World Storage

- To allow us to address some issues discovered, we have temporarily disabled cloud world storage on Windows. ([MCPE-241385](https://bugs.mojang.com/browse/MCPE-241385))
