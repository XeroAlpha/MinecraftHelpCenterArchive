**Posted:** 5 November 2026

A new hotfix is rolling out to address issues found in the latest update. It will become available on each platform as it’s approved, so please allow a little time for it to reach you.

## Graphical[](https://dev.azure.com/dev-mc/Minecraft/_wiki/wikis/Minecraft.wiki/43017/R26U6-Hotfix-2?anchor=graphical)

- Fixed an issue where block selection prevents interaction with entities inside blocks

## Stability and Performance[](https://dev.azure.com/dev-mc/Minecraft/_wiki/wikis/Minecraft.wiki/43017/R26U6-Hotfix-2?anchor=stability-and-performance)

- Improve stability on Xbox when under significant memory pressure
- Fixed a crash that could occur on Nintendo Switch 2 when rendering scenes with a large number of objects

## Realms[](https://dev.azure.com/dev-mc/Minecraft/_wiki/wikis/Minecraft.wiki/43017/R26U6-Hotfix-2?anchor=realms)

- Fixed an issue where cached cloud sync settings could sometimes overwrite config values used during a Realms purchase
