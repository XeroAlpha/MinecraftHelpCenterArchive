**Posted:** 25 September 2026\
\
A new hotfix is rolling out to address issues found in the latest update. It will become available on each platform as it’s approved, so please allow a little time for it to reach you.

## Stability and Performance[](https://dev.azure.com/dev-mc/Minecraft/_wiki/wikis/Minecraft.wiki?wikiVersion=GBwikiMaster&_a=edit&pagePath=/Bedrock%20Release%20Schedule/Changelogs/Full%20Release%20Changelogs/R26U5%20Full%20Changelog/R26U5%20Hotfix%202&pageId=41406&anchor=stability-and-performance)

- Improved stability for Nintendo Switch devices connected to a network
- Fixed an issue that could prevent the game from launching on some iOS devices ([MCPE-242503](https://bugs.mojang.com/browse/MCPE-242503 "https://bugs.mojang.com/browse/mcpe-242503"))

## Graphical[](https://dev.azure.com/dev-mc/Minecraft/_wiki/wikis/Minecraft.wiki?wikiVersion=GBwikiMaster&_a=edit&pagePath=/Bedrock%20Release%20Schedule/Changelogs/Full%20Release%20Changelogs/R26U5%20Full%20Changelog/R26U5%20Hotfix%202&pageId=41406&anchor=graphical)

- Corrected detection of cube-map array texture support on older Windows graphics hardware
- Fixed some inventory items appearing invisible with non-default Display Brightness and anti-aliasing set to 1 ([MCPE-241108](https://bugs.mojang.com/browse/MCPE-241108))

## Gameplay[](https://dev.azure.com/dev-mc/Minecraft/_wiki/wikis/Minecraft.wiki?wikiVersion=GBwikiMaster&_a=edit&pagePath=/Bedrock%20Release%20Schedule/Changelogs/Full%20Release%20Changelogs/R26U5%20Full%20Changelog/R26U5%20Hotfix%202&pageId=41406&anchor=gameplay)

- Players in Spectator Mode are no longer hit by projectiles ([MCPE-242446](https://bugs.mojang.com/browse/MCPE-242446))
- Cushions in unloaded chunks no longer disappear when the chunk reloads ([MCPE-241970](https://bugs.mojang.com/browse/MCPE-241970))

## Add-Ons[](https://dev.azure.com/dev-mc/Minecraft/_wiki/wikis/Minecraft.wiki?wikiVersion=GBwikiMaster&_a=edit&pagePath=/Bedrock%20Release%20Schedule/Changelogs/Full%20Release%20Changelogs/R26U5%20Full%20Changelog/R26U5%20Hotfix%202&pageId=41406&anchor=add-ons)

- Fixed an issue where older worlds with activated add-ons originating from the Marketplace disabled achievements at and after version 26.50 ([MCPE-242586](https://bugs.mojang.com/browse/MCPE-242586 "https://bugs.mojang.com/browse/mcpe-242586"))

## User Interface[](https://dev.azure.com/dev-mc/Minecraft/_wiki/wikis/Minecraft.wiki?wikiVersion=GBwikiMaster&_a=edit&pagePath=/Bedrock%20Release%20Schedule/Changelogs/Full%20Release%20Changelogs/R26U5%20Full%20Changelog/R26U5%20Hotfix%202&pageId=41406&anchor=user-interface)

- First-use onboarding now starts the selected multiplayer world while the player's Character Creator appearance is still loading
