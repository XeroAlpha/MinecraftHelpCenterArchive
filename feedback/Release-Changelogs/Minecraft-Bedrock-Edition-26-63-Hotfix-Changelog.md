**Posted:** 11 November 2026

A new hotfix is rolling out on Windows, Servers, and PlayStation 5 to address issues found in the latest update. It will become available on each platform once approved, so please allow a little time for it to reach you.

# Fixes[](https://dev.azure.com/dev-mc/Minecraft/_wiki/wikis/Minecraft.wiki/43727/R26U6-Hotfix-3?anchor=fixes)

## Gameplay[](https://dev.azure.com/dev-mc/Minecraft/_wiki/wikis/Minecraft.wiki/43727/R26U6-Hotfix-3?anchor=gameplay)

- Fixed an issue on the first connection to experiences that could prevent certain multiplayer features from working correctly

## Stability and Performance[](https://dev.azure.com/dev-mc/Minecraft/_wiki/wikis/Minecraft.wiki/43727/R26U6-Hotfix-3?anchor=stability-and-performance)

- Fixed an issue that could cause the game to get stuck at 73% during startup on Windows ([MCPE-243914](https://bugs.mojang.com/browse/MCPE-243914) ) 

## Editor[](https://dev.azure.com/dev-mc/Minecraft/_wiki/wikis/Minecraft.wiki/43727/R26U6-Hotfix-3?anchor=editor)

- Pro Realms Editor projects now start with simulation running the first time they load on a Realm, and worlds uploaded to a Realm drop items from environmental destruction such as water-killed crops
