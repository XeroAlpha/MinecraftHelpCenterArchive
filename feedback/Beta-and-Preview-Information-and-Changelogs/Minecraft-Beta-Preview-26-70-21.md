**Posted:** 20 October 2026

### **Information on Minecraft Preview and Beta:**

- These work-in-progress versions can be unstable and may not be representative of final version quality
- Minecraft Preview is available on Xbox, PlayStation, Windows, and iOS devices. More information can be found at [aka.ms/PreviewFAQ](https://aka.ms/PreviewFAQ)
- The beta is available on Android (Google Play). To join or leave the beta, see [aka.ms/JoinMCBeta](https://aka.ms/JoinMCBeta) for detailed instructions

Test more features from the upcoming game drop! Let the temperature drop indoors as well as outdoors by building a blue base out of packed ice bricks! Turn packed ice blocks into a full set, including packed ice bricks, slabs, stairs, walls, and chiselled blocks. While you're collecting all the ice you need for your shivering shelter, enjoy the ambience from across frozen rivers and oceans. Ice blocks over water and surrounded by more ice emit eerie singing sounds, sending a haunting echo through the ice caves.

And as always, we're keen to get your feedback on these new features at [feedback.minecraft.net](https://feedback.minecraft.net/), and you can report any bugs you find at [bugs.mojang.com](https://bugs.mojang.com/).

## Drop 4 of 2026 Features

### Blocks

- Introduced Packed Ice Bricks
  - A new blue tinted brick block set
  - A decorative block
  - Building block in the same vein as other brick block sets
  - Does not melt
  - Best tool is Pickaxe
- Updated Jukebox top and bottom MERS textures ([MCPE-243624](https://bugs.mojang.com/browse/MCPE-243624))
- Updated Icicle tip MERS textures ([MCPE-243638](https://bugs.mojang.com/browse/MCPE-243638))
  - Known Issues: Naming, instrumental sounds, Creative Inventory placement, and waterlogged behavior are still being finalised.

### Ice Ball

- Increased Ice Ball base damage to 2, with damage decreasing as it loses velocity

### Ice Caves

- Players can now fall into caves beneath Crevasses when Brittle Ice breaks
- Crevasses now generate at a more consistent density in Ice Caves with different ceiling heights

### Items

- The Ice Crystal item now has a MERS texture ([MCPE-243311](https://bugs.mojang.com/browse/MCPE-243311))
- Potions of Freezing can now be extended with Redstone Dust ([MCPE-243361](https://bugs.mojang.com/browse/MCPE-243361))

### Mobs

- Frostbites now hold Shields in the same position as other Zombies
- Cows, Pigs, Chickens, and Frogs now spawn as their cold variants when using Spawn Eggs in Ice Caves
- Wither Skeletons can now pick up Ice Balls
- Polar Bears, Snow Golems, and Strays are now immune to the Freezing status effect ([MCPE-243322](https://bugs.mojang.com/browse/MCPE-243322))
- Frostbite no longer spawns naturally underground outside the Ice Caves biome
- Polar Bears can no longer spawn on Brittle Ice

### Sounds

- Added ambient sounds for Ice blocks
  - When an ice block has at least 8 blocks of ice in both east, west, north and south horizontally, one airblock above and one waterblock below, a sound has a chance to play from the ice block.
- Packed, Blue and Frosted ice blocks now have their own sound events with ice sounds, not using "glass" any longer
- Added closed captions for when Frostbite converts to Zombie and Zombie converts to Frostbite
- Ambient music is now muted when players return within range of a playing Jukebox after leaving its broadcast range

## Features and Bug Fixes

### Accounts

- Improved loading time of player profile overview tab

### Blocks

- Honey Blocks once again provide support on every face ([MCPE-242222](https://bugs.mojang.com/browse/MCPE-242222))
- Breaking a Cushion or Armor Stand near a Sculk Catalyst no longer spreads Sculk ([MCPE-243530](https://bugs.mojang.com/browse/MCPE-243530))

### Gameplay

- Fixed issue where add-on imports could create pack folders with trailing periods that are inaccessible on Windows ([MCPE-235491](https://bugs.mojang.com/browse/MCPE-235491))
- The freezing screen overlay no longer lingers after respawning when a player dies with the Freezing effect
- The health bar now updates correctly when a Totem of Undying activates
- Mining Fatigue now reduces mining speed by the same amount as in Java Edition
- Haste and Conduit Power now increase mining speed by the same amount as in Java Edition
- Aligned Frost Walker with its intended behavior
  - Water now freezes in a circular area around the wearer, removing directional bias from the ice trail
  - Water now freezes only while the wearer is on the ground, preventing fatal fall damage caused by Frosted Ice forming beneath them while diving into Water

### Graphical

- The duration of The End flash now matches the Java Edition. ([MCPE-237012](https://bugs.mojang.com/browse/MCPE-237012))
- Fixed the illumination of transparent particles in Vibrant Visuals
- Skulls and Chests now face the player in first person and away from the player in third person view
- Shield, Crossbow, Spears and Spyglass animate correctly in first person view when selected

### Items

- Fixed an issue where some continuously used items, like the Spyglass, would continue being used after changing dimensions without player input if the player entered a portal while using it ([MCPE-220815](https://bugs.mojang.com/browse/MCPE-220815))
- Splash potions, lingering potions, and XP bottles now display the correct captions when breaking
- Wind Charge now displays the correct caption when thrown
- Wind Charge now plays the correct sound when thrown ([MCPE-243320](https://bugs.mojang.com/browse/MCPE-243320))
- Fixed the first and third person transforms of various items to be more in line with Java

### Mobs

- Fixed difficulty scaling for damage dealt to players by mob-fired projectiles, matching Java Edition
- Increased Guardian base attack damage from 5 to 6 and Elder Guardian base attack damage from 5 to 8, matching Java Edition
- Damage dealt to players by Evoker Fangs now scales with difficulty, matching Java Edition

### Marketplace

- Fixed an issue on Android where searching from the Marketplace search results page could send players back to the Marketplace front page or main menu

### Music Features Add-On

- The new Music Features Add-On pack is coming to Minecraft. This is a free add-on that is already built into your game, meaning that when you load the game you will already have the pack! You do not need to go to Marketplace to download it.
- Press songs onto blank discs with the new Disc Press, play your track discs in a Jukebox, or bring the music along with you in the Pocket Jukebox! To access these new blocks, items, and features, add the "Music Features Add-On" resource pack to your world. There will be a matching behavior pack that will be added. **Note that these features won't work with Realms yet.** Let us know what you think at [Minecraft Feedback](https://aka.ms/mc-MusicFeaturesAddOn) and report any bugs at [bugs.mojang.com](http://bugs.mojang.com/)

#### Blank Disc

- Blank discs are craftable discs that can be used in the disc press to create Track Discs.

#### Disc Press

- Disc Press is a new kind of block which can press music onto blank discs to create Track Discs. The disc press in Preview comes with pre-packaged Minecraft main menu songs so you can press music right away.
- Note that if Disc Press appears empty you may need to restart your game.

#### Pocket Jukebox

- Pocket Jukebox is an item that lets you listen to music on the go. It can be filled with up to 20 Track Discs or Vanilla Music Discs. Music from the Pocket Jukebox is only heard by the player using it.
- The color of the pocket jukebox is determined by the color of the bundle used to craft it. You can also dye the pocket jukebox after it's been crafted.

#### Track Disc

- Track Discs are created in the Disc Press and can be played in a Jukebox or Pocket Jukebox.

### Realms

- Fixing an issue where an upload could fail during the processing step due to an unexpected block error
- Fixed sim distance setting description not reflecting correct range text

### Stability and Performance

- Fixed issues with worlds not saving correctly when the game is suspended or closed
- Fixed a crash that could occur after staying in the menus for a long time
- Deferred and limited background server status requests to reduce delays during sign-in and menu loading

### User Interface

- Arabic and Persian text in-game is now shown with joined letters and in right-to-left order, including in chat, on signs and while typing ([MCPE-235981](https://bugs.mojang.com/browse/MCPE-235981))
- External link buttons in settings now properly animate before opening in the browser on all platforms
- Xbox P2P invites received while in-game can now be found in the Social Drawer ([MCPE-34914](https://bugs.mojang.com/browse/MCPE-34914))
- Disabled block light quality options "High" and "Ultra" if they are unsupported.

## Technical Updates

### API

- Added the BlockSearchOptions interface for Dimension.getBlockAbove and Dimension.getBlockBelow, replacing BlockRaycastOptions. Existing fields and whole-block search behavior are unchanged; existing option objects still work
- Raycast maxDistance values outside -2147483648 to 2147483647 now throw PropertyOutOfBoundsError before truncation
- Fixed entities with minecraft:item_hopper to fire EntityItemPickupAfterEvent when consuming an entire item stack and to report only the transferred amount in items for partial pickups, without emitting events for unsuccessful pickups
- Releasing PrimitiveShape properties hiddenFrom and defaultVisibleToAll from beta to V2.12.0.
- Released block point-of-interest APIs from beta to v2.12.0
- Added GamePadAndMouse as a member of InputMode
- ItemBlockDynamicPropertiesComponent and ItemBlockEntityStorageComponent may no longer be accessed on Vanilla items
- Renamed the item component minecraft:block_actor_dynamic_properties to minecraft:block_dynamic_properties

#### @minecraft/server-ui

- Released MessageBoxOptions and the optional MessageBox constructor options parameter to stable version 2.4.0, including showHorizontalButtons for horizontal button layouts
- Released CustomForm.multiButtonRow, ButtonData, and MultiButtonRowOptions to stable version 2.4.0

#### EditorStructureManager

- Fixed createFromClipboardItem saving the primary clipboard instead of the supplied clipboard item

#### Server-ui

- Released version 2.4.0 of @minecraft/server-ui
- Added 2.5.0 beta of @minecraft/server-ui.

### Block Components

- Modified minecraft:destructible_by_mining component renamed seconds_to_destroy field to base_time_to_destroy
- Fixed custom full blocks rotated with minecraft:transformation not hiding faces covered by adjacent blocks with voxel shapes ([MCPE-241209](https://bugs.mojang.com/browse/MCPE-241209))
- Blocks using the state minecraft:sixteen_way_rotation now correctly rotate and mirror when loaded as part of structure ([MCPE-243539](https://bugs.mojang.com/browse/MCPE-243539))

### Editor

- Added a Bake All Layouts action to the Layouts Management pane, which permanently bakes every Layout instance in every dimension into the world and removes the instances. It shows its progress in a blocking dialog with a Stop button and cannot be undone
- Baking a single Layout instance from the Layout editor no longer stalls the editor
- The Layouts Management pane now refreshes when Layouts or Layout instances are changed outside the pane
- Add additional sort options for Layouts. Added Layouts Tags management support and sort by Tags.
- Fixed the tag container background color when using the inverted variant supplied through a facet
- Fixed a bug that caused a phantom layout entry to appear when exiting Layout Editor.

### Entity Components

#### minecraft:projectile

- Added scale_damage_with_difficulty to on_hit.impact_damage for entity format versions 1.26.70 and later, controlling whether impact damage dealt to players by mob-fired projectiles scales with world difficulty
- scale_damage_with_difficulty defaults to true; set it to false to disable difficulty scaling. Entities using earlier format versions retain their previous behavior with difficulty scaling disabled

### Mobs

- Internal only Vex goals are no longer listed in legacy goal documentation

## Experimental Technical Updates

#### Graphical

- Fixed light leaking in Vibrant Visuals when Block Light Quality is set to Medium

### API

- Added the beta usePreciseRaycast option to BlockRaycastOptions and EntityRaycastOptions to preserve fractional distances and check the full ray. It defaults to false, preserving legacy behavior, and does not apply to BlockSearchOptions
- Entity raycasts with usePreciseRaycast enabled throw InvalidArgumentError for negative maxDistance values

#### GameTest Command

- Added new version for the runset command for GameTest which may run multiple tags in a single command. Ex. the command, /gametest runset SetA SetB, will now run all tests tagged as SetA or SetB.
- runset now allows for a withoutTags flag to be added which ignores any tests with the specified tags. Ex. the command, /gametest runset SetA withoutTags SetB, will run all tests from SetA that do not also have the tag SetB.
- Adjusted the parameter rotationSteps in runset to be explicit rather than implicit. Ex. Previously, a command such as /gametest runset SetA 2 would read the rotationSteps, 2, after the specified tag, SetA. Now the rotationSteps flag must be declared before its value as such, /gametest runset SetA rotationSteps 2

### Entity Filters

- Added the speed entity filter for comparing an entity's speed in meters per second
- Added the horizontal_speed entity filter for comparing an entity's horizontal speed in meters per second
- Added the vertical_speed entity filter for comparing an entity's signed vertical speed in meters per second

### Graphical

- Fixed lighting artifacts on terrain when Block Light Quality was Medium or higher
  - Updated the contribution ratio between point lights and block lights

### Network Protocol

- Added enum value GameTestRunSetMultiTag to CurrentCmdVersion.
