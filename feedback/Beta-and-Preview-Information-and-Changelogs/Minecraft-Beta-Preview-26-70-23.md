### **Information on Minecraft Preview and Beta:**

- These work-in-progress versions can be unstable and may not be representative of final version quality
- Minecraft Preview is available on Xbox, PlayStation, Windows, and iOS devices. More information can be found at [aka.ms/PreviewFAQ](https://aka.ms/PreviewFAQ)

The final features from the upcoming game drop are ready for testing! The long-awaited calcite brick set doesn't just bring one, but two, new variants for builders! Regular calcite can be turned into walls, stairs, and slabs but polished calcite can also be used for pillars, bricks, double slabs and more! Their marble-like pallor instantly adds a fancy flair to any winter wonderland. And why not add some mystery while you're at it? The new music disc composed by Hyper Potions can be found in igloo basements and will set the tone for even more ice cold digging. Have you added it to your jukebox playlist yet?

And as always, we're keen to get your feedback on these new features at [feedback.minecraft.net](https://feedback.minecraft.net/), and you can report any bugs you find at [bugs.mojang.com](https://bugs.mojang.com/).

## Drop 4 of 2026 Features

### Block set

- Introduced Calcite Blocksets
  - Calcite Stairs, Slab and Wall are added matching the already existing Calcite Block
  - Added Polished Calcite Blockset
  - Added Polished Calcite Brick Blockset
  - Added Calcite Pillar Block
  - They are all Decorative blocksets
  - They are all Building blocks

### Blocks

- Jukeboxes no longer emit vibrations when taking or swapping a Music Disc from their playlist
- Packed Ice Bricks and Chiseled Packed Ice now conduct redstone signals
- Packed Ice Brick Walls no longer prevent Chests from opening ([MCPE-243816](https://bugs.mojang.com/browse/MCPE-243816))
- Packed Ice and Packed Ice Bricks can now be used in a Stonecutter to make Packed Ice Bricks, Packed Ice Brick Slabs, Packed Ice Brick Stairs, Packed Ice Brick Walls, and Chiseled Packed Ice ([MCPE-243782](https://bugs.mojang.com/browse/MCPE-243782))
- Brittle Ice, Packed Ice Bricks, Chiseled Packed Ice, and Snow Bricks now block light correctly, so mobs underneath no longer burn in daylight
- All parts of the Packed Ice Bricks set now play the correct sounds

### Freezing Mob Effect

- Being on fire now prevents freezing from building up until the fire goes out
- Standing in fire or lava while freezing no longer plays the fizz sound and particles continuously

### Ice Ball

- Being killed by an Ice Ball now shows the correct death message ([MCPE-243703](https://bugs.mojang.com/browse/MCPE-243703))

### Items

- Added a new music disc with the song "flurry" by composer Hyper Potions
  - This music disc has a 30% chance to be found inside Igloo chests

### Entities

- Added the Beta-only field to an entity's description field clear_behaviors_on_component_changes to opt into clearing a mob's existing AI components when any component changes occur; it defaults to false for Beta documents

### Entity Components

- Added a new minecraft:entity_rotation_always_follows_head entity component, available to entity definitions using the beta format version, which keeps the entity's rotation aligned with its head after look behaviors run
  - It overrides the yaw set by movement components, so it is intended for entities that turn in place
- Added a new minecraft:spherical_look_control entity component, which turns the entity's head toward targets set by look behaviors along the shortest arc in 3D, combining upward or downward rotation (pitch) with side-to-side rotation (yaw) in a single turn
  - Look requests turn at the average of the pitch and yaw speeds supplied by the look behavior, optionally scaled by distance
  - With no look request, the head keeps its current direction unless its pitch is outside pitch_limits, in which case it returns toward the nearest limit at pitch_recovery_speed
  - pitch_recovery_speed: The speed in degrees per second used to return the head's pitch within pitch_limits when no look request is present, from 0 to 3600, defaulting to 60
    - Set to 0 to disable pitch recovery when no look request is present
    - Does not limit turning toward requested targets
  - reference_distance: An optional positive distance in blocks at or below which the look behavior's average pitch and yaw speed applies unchanged
    - Beyond this distance, turn speed is multiplied by reference_distance divided by the target distance, so doubling the distance halves the speed
    - Distance is measured from the entity's breathing point to the requested look position
    - Applies only to position targets, with distance scaling disabled when omitted
  - pitch_limits: The min and max pitch in degrees, from -90 (straight up) to 90 (straight down) and defaulting to -90 and 90
    - Set both to the same value for a fixed pitch
  - Only available to entity definitions using the beta format version

#### minecraft:projectile

## Experimental Technical Updates

### API

- Added includeNamespace and excludeNamespace to BiomeFilter
  - If a namespace is added to includeNamespace, a biome using that namespace can be found
  - If a namespace is added to excludeNamespace, a biome using that namespace cannot be found
- Added includeNamespace and excludeNamespace to BlockFilter
  - If a namespace is added to includeNamespace, a block using that namespace can be found
  - If a namespace is added to excludeNamespace, a block using that namespace cannot be found
- Added namespaces and excludeNamespaces to EntityFilter
  - If a namespace is added to namespaces, an entity using that namespace can be found
  - If a namespace is added to excludeNamespaces, an entity using that namespace cannot be found
- Added world.afterEvents.portalActivate, PortalActivateAfterEvent, and PortalActivateAfterEventSignal to @minecraft/server in beta to notify scripts after a Nether portal is activated, providing its dimension, ignition location, and initiating player when known
- Added property ItemCustomComponent.onReleaseUse to beta
- Added two new methods to BlockEntityStorageComponent and ItemBlockEntityStorageComponent, still behind beta:
  - remove removes a stored entity from the current content pack's storage without releasing it into the world. No entity, experience, or item drops are spawned.
  - totalSize returns the total number of entities stored in this block's entity storage across all content packs.

### Actor

- Passenger of block will now take into account the rotation limit they were given
- Passenger of block will stop being passenger when their supporting block is removed or replaced with a different block type

#### PlayerDimensionChangeAfterEvent

- Added the beta read-only source property, which reports what caused the player to change dimensions using the new PlayerDimensionChangeSource enum

#### PlayerDimensionChangeSource

- Added the beta PlayerDimensionChangeSource enum with the values Portal, TeleportCommand, PlayerRespawn, and Unknown

### Blocks

- minecraft:collision_box has been updated to support voxel shape identifiers as a collision shape from 1.26.70 and onwards:
  - Requires the "Voxel Shapes" experiment. Using the component as a 'bool' or a box array remains non-experimental.
  - Identifiers can be a custom voxel shape, minecraft:unit_cube, or minecraft:empty.
  - Voxel shapes that exceed the collision bounds of \[0,0,0\] to \[16,24,16\] will be clamped and registered with a warning. "format_version": "1.26.70", "identifier": "test:block_v1_26_70" "minecraft:collision_box": "custom:collision_shape"

### Ore UI Emoji

- Support existing custom Minecraft emoji Unicode code points in Ore UI screens
