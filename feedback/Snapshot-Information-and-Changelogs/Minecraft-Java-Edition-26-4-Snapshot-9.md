**Published** 11/17/26

26.4 Snapshot 9 is here, bringing data-driven dispensers, Vulkan as the default graphics backend, and a new setting to fine-tune your fog. We've also made improvements to keyboard navigation and narration, alongside a few other tweaks and fixes!

Happy mining!

## Changes

- Added a Repeat Recipe/Trade keybind that repeats the last recipe or trade used
- Added a separate "Improved Fog" video setting that allows to control the Improved Fog feature independently of the "Improved Transparency" video setting
- Vulkan is now the default graphics backend, rather than being randomized, and is no longer considered experimental

> **Developer's Note**: *The plan is to ship 26.4 with Vulkan graphics API being the default one unless any critical issues are discovered before the full release*

### A Separate "Improved Fog" Video Setting

- Separated the "Improved Fog" video setting from the "Improved Transparency"
- Turning it on together with the "Improved Transparency" will behave the same way as the previous Snapshot with "Improved Transparency" enabled: both sky and clouds will be blended into the terrain render distance fog
- Turning it on without "Improved Transparency" will only blend the sky but not the clouds
- You can now use "Improved Transparency" without "Improved Fog" if you don't like the effect
- The performance impact of "Improved Fog" is minimal, but it may be noticeable on lower-end hardware
- The setting is enabled by default
- It is disabled on the "Fast" graphics preset and enabled on the "Fancy" and "Fabulous" graphics presets

### Minor Tweaks to Blocks, Items and Entities

- The random boost time for using a Carrot or Warped Fungus on a Stick while riding a Pig or Strider respectively is now between 7 and 35 seconds

### Sounds

- Fire and Soul Fire now use the extinguish sound as their block break sound, including when their supporting block is removed

### UI

- Recipe Book tabs now show their category as a tooltip
- Recipes in the Recipe Book are now highlighted when hovered or focused

#### Friends

- Improved the reliability and speed of friend availability updates

### Accessibility

#### Gameplay Screen Keyboard Navigation

- The Recipe Book can now be used with the keyboard
  - Tab moves between the tab buttons, search box, filter button, recipes, and page buttons
  - Enter/Space on a recipe places it in the crafting grid, and holding Shift places as many as possible
  - Control + Enter on a recipe opens the popup of alternative recipes, like right-clicking
    - The arrow keys move within the popup, and Escape or Tab closes it
  - Repeating the last selected recipe has moved from Space and Enter to the new Repeat Recipe/Trade key (R by default), and holding Shift still places as many as possible
- The Repeat Recipe/Trade key also repeats the last selected trade in the Villager and Wandering Trader screens
- The Creative Inventory can now be used with the keyboard

#### Gameplay Screen Narration

- The narrator now reads out the Recipe Book
  - Recipes are narrated with their result and their column and row in the grid
  - The tabs, search box, and filter button are narrated with their names
  - The page buttons narrate the current page
  - Recipes in the alternative recipes popup are narrated with their position, and the narrator mentions that Escape closes it
- The narrator now reads out the Creative Inventory
  - Tabs are narrated with their name and position
  - Items are narrated with their column and row in the grid

## Technical Changes

- The Data Pack version is now 128.0
- The Resource Pack version is now 104.0

### Network Protocol

#### Modified Login Protocol

- Changed encryption key establishment procedure

### Dedicated Server Properties

- Added key-rotation-period-seconds field
  - Determines the minimum duration after which server keys (used for establishing new connections) will be recreated
  - If set to 0 a unique (i.e. ephemeral) key will be used for every connection
  - Default value: 60

## Data Pack Versions 122.0 through 128.0

- Dispense behaviors are now data-driven

### Commands

#### Added support for local arguments in 2D coordinates

- Arguments in form of ^\<left\> ^\<forwards\> are now accepted in commands that take 2D coordinates:
  - Chunk coordinates in forceload
  - spreadplayers \<center\>
  - worldborder center \<pos\>
- Only takes into account player rotation around Y axis (as opposed to interpreting that as ^\<left\> ^0 ^\<forwards\> and casting to XZ plane)

### Dispense Behaviors

A new registry folder: dispense_behavior. Each file is a list of behaviors that describe a sequence of behaviors to attempt when dispensing an item. Unless otherwise noted, behaviors are tried in sequence until one succeeds.

Each entry has a type field specifying a dispense behavior type as described below, possibly with type-specific additional fields.

Vanilla entries:

- minecraft:armor_stand - Used for Armor Stands
- minecraft:boat - Used for all types of Boats, Chest Boats, Rafts and Chest Rafts
- minecraft:bone_meal - Used for Bone Meal
- minecraft:brush - Used for Brushes
- minecraft:carved_pumpkin - Used for Carved Pumpkins
- minecraft:chest - Used for Chests (note: only default Chests, not Trapped, Copper or other types of Chests)
- minecraft:default - Used for any items without another specified behavior
- minecraft:default_projectile - Used for all types of Arrows, all types of Eggs, Snow Balls and Ice Balls
- minecraft:dropper - Used for all item types by Droppers
- minecraft:empty_bucket - Used for empty Buckets
- minecraft:equipment - Used for all types of equippables except Carved Pumpkins and Wither Skeleton Skulls
- minecraft:filled_bucket - Used for all types of Buckets with any contents
- minecraft:fire_charge - Used for Fire Charges
- minecraft:firework_rocket - Used for all Firework Rockets
- minecraft:flint_and_steel - Used for Flint & Steel
- minecraft:glass_bottle - Used for empty Glass Bottles
- minecraft:glowstone - Used for Glowstone Blocks
- minecraft:honeycomb - Used for Honeycombs
- minecraft:minecart - Used for all types of Minecarts
- minecraft:potion - Used for Potions (note: only default Potions, not Splash or Lingering)
- minecraft:shears - Used for Shears
- minecraft:shulker_box - Used for all Shulker Boxes
- minecraft:spawn_egg - Used for all Spawn Eggs
- minecraft:thrown_potion - Used for Splash Potions and Lingering Potions
- minecraft:tnt - Used for TNT Blocks
- minecraft:wind_charge - Used for Wind Charges
- minecraft:wither_skeleton_skull - Used for Wither Skeleton Skulls

### Dispense Behavior Types

#### minecraft:brush_armadillo

- Brushes an Armadillo in front of the Dispenser
- No additional fields

#### minecraft:charge_respawn_anchor

- Charges a Respawn Anchor in front of the Dispenser
- If the Respawn Anchor is already fully charged, no further behaviors are tried
- No additional fields

#### minecraft:convert_to_mud

- Converts the block in front of the Dispenser to Mud in case it has the \#minecraft:convertible_to_mud block tag.
- The item needs to contain a Water potion, otherwise it fails
- No additional fields

#### minecraft:drop_item

- The item is dropped as an item entity
- No additional fields

#### minecraft:empty_bucket

- Empties the bucket in front of the Dispenser
- The item needs to be a bucket, otherwise it fails
- No additional fields

#### minecraft:equip

- Equips the item onto a living entity in front of the Dispenser
- The item must be equippable onto a slot of the entity
- No additional fields

#### minecraft:equip_chest

- Equips a Chest onto a tamed mob that can carry a Chest in front of the Dispenser
- No additional fields

#### minecraft:equip_sulfur_cube

- Gives the item to a Sulfur Cube in front of the Dispenser
- The item needs to be in the \#minecraft:sulfur_cube_swallowable item tag, otherwise it fails
- No additional fields

#### minecraft:fill_bottle

- Fills the bottle from the block in front
- No additional fields

#### minecraft:fill_bucket

- Picks up a fluid in front of the Dispenser, filling the bucket
- No additional fields

#### minecraft:grow_plant

- Grows a plant in front of the Dispenser
- No additional fields

#### minecraft:ignite

- Ignites the block in front of the Dispenser
- No additional fields

#### minecraft:insert_into_container

- Inserts the item into a container in front of the Dispenser
- No additional fields

#### minecraft:place_armor_stand

- Places an Armor Stand in front of the Dispenser
- No additional fields

#### minecraft:place_block

- Places the item as a block in front of the Dispenser
- The item needs to be a block item, otherwise it fails
- No additional fields

#### minecraft:place_boat

- Places a Boat on water in front of the Dispenser
- The entity type is determined by the minecraft:entity_data component of the item, and needs to be a Boat, Chest Boat, Raft or Chest Raft
  - For any other entity type, the action fails
- No additional fields

#### minecraft:place_minecart

- Places a Minecart on rails in front of the Dispenser
- The entity type is determined by the minecraft:entity_data component of the item, and needs to be a Minecart
  - For any other entity type, the action fails
- No additional fields

#### minecraft:shear

- Shears a mob or harvests a beehive in front of the Dispenser
- No additional fields

#### minecraft:shoot_projectile

- Shoots the item as a projectile
- The item needs to be a projectile item, such as an Arrow or Snowball
- Additional fields:
  - offset - vector of 3 doubles, the offset of the spawn position of the projectile from the center of the Dispenser
  - scale - double, how far from the offset position to spawn the projectile, along the direction of the Dispenser
  - uncertainty - non-negative float, the inaccuracy of the shot
  - power - non-negative float, the velocity of the shot
  - sound - optional object, the sound to play when shooting (defaults to minecraft:block.dispenser.launch with volume 1.0 and pitch 1.2)
    - sound - Sound Event to play
    - volume - float provider, the volume of the sound
    - pitch - float provider, the pitch of the sound

#### minecraft:spawn_golem_from_carved_pumpkin

- Completes a Golem in front of the Dispenser
- No additional fields

#### minecraft:spawn_mob

- Spawns the entity defined by the minecraft:entity_data component in front of the Dispenser
- No additional fields

#### minecraft:spawn_tnt

- Spawns Primed TNT in front of the Dispenser
- No additional fields

#### minecraft:transform_block

- Transforms the block in front of the Dispenser using a Block Transformer
- Additional field:
  - transformer - Namespaced ID of the Block Transformer to use

#### minecraft:spawn_wither_from_wither_skeleton_skull

- Completes a Wither in front of the Dispenser
- No additional fields

### Data Components

#### Added minecraft:dispense_behavior

Determines what happens when the item is dispensed from a Dispenser.

- Format: Namespaced ID of a dispense_behavior registry entry or an inline list of Dispense Behaviors

#### minecraft:entity_data

- Boat and Minecart items now have this component by default, determining which entity is placed when the item is used or dispensed
  - Entity types that do not match the type requirement result in the action failing

### Block Transformers

- Added block transformer minecraft:honeycomb
  - Used to wax blocks (currently only from dispensers)

### Particles

#### Changed minecraft:current_down

- Added new field radius - float, the radius around the position to spawn the particle at

#### Changed minecraft:bubble_column_up

- Added optional field pop_chance - float between 0.0 and 1.0, the chance that the particle will spawn a pop particle and play a pop sound once at the end of its lifecycle
  - If omitted, defaults to 0.0

### Dialogs

- The game will now show red text and a warning tooltip if the user appears to be entering an email address into a dialog input field

## Resource Pack Versions 98.0 through 104.0

  - All keys beginning with menu.custom_screen_info

### UI Sprites
